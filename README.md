# Vibe Todo

Минималистичный To-Do List для рабочих задач на React + Tailwind CSS.

## Особенности
- Чистый, воздушный дизайн
- Поле ввода с кнопкой «Добавить»
- Список задач с чекбоксами
- Кнопка удаления для каждой задачи
- Счетчик активных задач
- Адаптивный дизайн

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск development сервера
npm start
```

Приложение будет доступно по адресу http://localhost:3000

## Деплой

Для деплоя на production сервер http://192.168.223.76:3000/:

```bash
# Автоматический деплой
npm run deploy

# Или вручную
./deploy.sh
```

### Настройка сервера (выполняется один раз)

1. Установить Node.js и PM2 на сервере
2. Создать директорию `/var/www/vibe-todo`
3. Настроить PM2 конфигурацию

Подробная инструкция в `.windsurf/workflows/deploy.md`
